A responsive and modern transaction dashboard built with **HTML**, **CSS**, and **Tailwind CSS**. This project is designed to display transaction data in an intuitive and visually appealing way, featuring a sidebar navigation, transaction list, and status indicators.

---

## 🚀 Features

- **Responsive Design**: Fully optimized for different screen sizes.
- **Sidebar Navigation**: Easy access to different sections.
- **Transaction List**: Displays transaction details like game, item, price, and status.
- **Status Indicators**: Visual indicators for transaction statuses (Success, Pending, Failed).
- **Tab Menu**: Filter transactions by status.
